# برمِج — لغة برمجة عربية وبيئة تطوير كاملة

**برمِج** لغة برمجة عربية حقيقية (مفسّر كامل: محلل لغوي + محلل نحوي + مفسّر) ومعاها بيئة تطوير متكاملة في المتصفح — كل حاجة بتشتغل على جهازك، من غير سيرفر، مجانًا.

## جرّبها

افتح الموقع ودوس «شغّل»، أو افتح تبويب «الدروس» وابدأ تتعلم خطوة بخطوة.

## المميزات

- **لغة عربية كاملة**: متغيرات، شروط (لو/وإلا)، حلقات (كرر/طالما/لكل)، دوال، قوائم، قواميس، ٢٠+ دالة جاهزة
- **أرقام عربية وإنجليزية**: ١ + ٢ = 3 زي 1 + 2
- **محرر بإبراز صياغة** (syntax highlighting) وأرقام أسطر وحفظ تلقائي
- **رسائل خطأ بالعربي** ورقم السطر
- **٨ دروس تفاعلية** بتحقق تلقائي من الحل
- **٨ أمثلة جاهزة** بلمسة واحدة
- **مشاركة برابط**: الكود بيتخزن في الرابط نفسه
- **وضع ليلي ونهاري**، ومتجاوب مع الموبايل

## مثال

```
دالة فيبوناتشي(ن) {
  خلي أ = ٠
  خلي ب = ١
  كرر ن {
    اطبع أ
    خلي ت = أ + ب
    أ = ب
    ب = ت
  }
}
فيبوناتشي(١٠)
```

## تقنيًا

HTML + CSS + JavaScript خام (vanilla)، بدون أي مكتبات أو خطوة بناء. المفسّر في `lang.js` (~٤٠٠ سطر) بيشتغل في المتصفح وفي Node.
