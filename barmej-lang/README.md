# برمِج — لغة برمجة عربية وبيئة تطوير كاملة

**برمِج** لغة برمجة عربية حقيقية (مفسّر كامل: محلل لغوي + محلل نحوي + مفسّر مبني على generators) ومعاها بيئة تطوير متكاملة في المتصفح — كل حاجة بتشتغل على جهازك، من غير سيرفر، مجانًا.

## جرّبها

افتح الموقع ودوس «شغّل»، أو افتح تبويب «الدروس» وابدأ تتعلم خطوة بخطوة.

## المميزات

- **مكتبة `تاريخ`**: كبيسة، أيام الشهر، اسم الشهر/اليوم، عدد الأيام بين تاريخين (`استورد "تاريخ"`).
- **مكتبة `إحصاء`**: متوسط، وسيط، أكبر/أصغر، تباين، ترتيب للقوائم (`استورد "إحصاء"`).
- **🎓 ٩ مهام تعليمية جوه تبويب البلوكات**: مهمة لكل فكرة (اطبع، كرر، متغير، مربع، لو/وإلا، لكل، دالة، طالما، نجمة) بتتحقق من البلوكات المستخدمة ومن الناتج، مع زرار «ورّيني الحل» وتقدّم محفوظ.
- **📊 مكتبة مخططات + معالج المخططات**: `استورد "مخططات"` بتدّيك مخطط_أعمدة، مخطط_خطي، مخطط_دائري، شريط_نصي، اطبع_جدول، وزرار «📊 مخطط» في المحرر بيكتب الكود من بياناتك ويرسمه. ٦ أمثلة جديدة.
- **🏆 ٣٠ تحدي جديد (٦٦ تحدي دلوقتي)**: خرج متوقع واضح لكل تحدي وحل مقترح (💡)، وشريط تقدم وفلاتر (الكل/لسه/محلول) وبحث في قايمة التحديات. التحديات الجديدة في challenges2.js.
- **🧩 البلوكات ٢**: استيراد كود المحرر لبلوكات (📤 هات كود المحرر) بيفهم لو/وإلا لو/كرر/لكل/طالما/دالة وأي سطر تاني يبقى «نداء حر»، وبلوكات جديدة (دالة، ارجع، أضف، قف، كمل، كتلة)، وحفظ برامج بلوكات بأسماء.
- **🧩 برمجة بالبلوكات** (تبويب جديد): ١٥ نوع بلوك ملوّن (اطبع، خلي، كرر، لكل، طالما، لو/وإلا، رسم، استنى…) بتتضاف بضغطة جوه أي بلوك، بتعدّل قيمها وترتّبها (▲▼ نسخ ✕)، والكود العربي الحقيقي بيتولّد لحظيًا وتشغّله في المحرر. بتتحفظ تلقائي ومعاها مثالين.
- **📖 مرجع الدوال**: في تبويب الدليل، ١١٠ دالة جاهزة (نصوص، قوائم، رياضيات، رسم، صوت، مكتبات) بالبحث والتصنيف، وكل واحدة بمثال تشغّله في مكانه (▶ جرّبه) أو تبعته للمحرر.
- **لغة عربية كاملة**: متغيرات، شروط (لو/وإلا)، حلقات (كرر/طالما/لكل)، دوال، قوائم، قواميس، ٥٠+ دالة جاهزة (رياضيات ومثلثات وقوائم ونصوص)
- **أرقام عربية وإنجليزية**: ١ + ٢ = 3 زي 1 + 2
- **تتبع حي للتنفيذ**: السطر اللي بينفذ دلوقتي بينور بالأخضر وأنت بتتفرج
- **تنفيذ خطوة بخطوة 👣**: نفّذ برنامجك سطر سطر، شوف السطر الحالي بينور، وراقب قيم المتغيرات لحظة بلحظة
- **ألعاب حية**: `استنى` للتوقف المؤقت و`مفتاح` لقراءة الكيبورد — اعمل لعبتك التفاعلية
- **رسم بالقلم**: أوامر رسم كاملة (قدم/يمين/دائرة/مستطيل/املأ/نص على اللوحة) + حفظ الرسمة كصورة PNG
- **أصوات ونغمات**: `نغمة("دو")` و`صوت(تردد)` بأسماء النغمات العربية
- **محرر بإبراز صياغة** وأرقام أسطر واقتراحات تلقائية وحفظ تلقائي
- **برامج متعددة**: درج «برامجي» يحفظ برامج كتير بالاسم في متصفحك
- **رسائل خطأ بالعربي** ورقم السطر مع تظليل السطر الغلط
- **٧٢ درس تفاعلي** بتحقق تلقائي + **٣٦ تحدي** + **١٦٧ مثال جاهز: ألعاب كاملة (ثعبان، إمساك تفاح) ورسوم متحركة وفركتلات (شجرة، ندفة كوخ)**
- **📚 ١٠ دروس جديدة (٦٣-٧٢)** في ملف lessons2.js: مكدس، طابور، أطول كلمة، جدول الضرب، دمج قوايم مترتبة، أطول تكرار، متوسط ومدى، اختبار الدوال بزرار 🧪، قوايم متداخلة، والقوسين المتوازنين. كلها بتلميح وحل مجرّب.
- **📊 إنجازي** (تبويب جديد): لوحة تقدّم: مستوى ونقاط، سلسلة أيام، تقدّم الدروس والتحديات والمشاريع والمسار، خريطة نشاط ١٦ أسبوع، أوسمة، وزرار «كمّل من حيث وقفت».
- **🎯 اعمل تحدي وشاركه برابط** (زرار «اعمل تحدي»): اكتب مهمة وكود بداية ومخرجات متوقعة (بتتولّد من حلك)، وانسخ رابط `#ch=`؛ أي حد يفتحه يلاقي المهمة وشريط «تحقق» بيصحح كوده ويقوله السطر اللي غلط فيه.
- **🧪 مختبر الاختبارات** (زرار «اختبر»): اكتب حالات `نداء => متوقع` لدوالك وشغّلها كلها، مع شريط نجاح، ومولّد حالات من سلوك كودك الحالي.
- **🧠 اشرح الكود** (زرار «اشرح» في المحرر): بيحوّل أي برنامج لشرح عربي بسيط سطر بسطر مع إحصائيات، ودوس على الشرح يوديك للسطر.
- **🔍 فاحص الكود** (زرار «افحص» في المحرر): مراجعة ساكنة بدون تشغيل: متغيرات مش مستخدمة، أسماء غلط مع اقتراح، دوال بتنادي نفسها من غير شرط، حلقات للأبد، قسمة على صفر، كود ميت، تداخل زيادة، دوال طويلة، وتقييم من ١٠٠ مع قفز للسطر.
- **💡 تلميح بخطوتين وحل مقترح لكل درس من الـ٧٢** (كل الحلول متجرّبة إنها بتعدّي تحقق الدرس).
- **🖼️ معرض أعمالي**: صور مصغّرة تلقائية لبرامجك المحفوظة، بحث، فتح وتشغيل بضغطة ورابط مشاركة لكل برنامج.
- **🕰️ مصحّح بالرجوع في الزمن**: خطوة بخطوة مع زر «السابقة» وسلايدر لأي خطوة، رسم بياني صغير لتغيّر كل متغيّر، وأكتر الأسطر تنفيذًا.
- **🎓 مسار تعليمي من ٥ مستويات** بامتحانات متصحّحة تلقائي (٢٥ سؤال، إجابات الأكواد متحقق منها بتشغيلها) وشهادة اجتياز المسار.
- **🏗️ مشاريع موجّهة (٥ مشاريع × ٥ خطوات، منهم ٢ رسم بمعاينة حيّة)**: بتبني برنامج كامل خطوة خطوة، كل خطوة بتتحقق تلقائي، وتقدّمك وكودك بيتحفظوا، مع تلميح وحل وفتح في المحرر.
- **أصناف ودوال بلا اسم**: `صنف` و`يرث` و`خريطة/صفّي/اختزل`، ومكتبات بـ`استورد`
- **ألعاب حقيقية**: ماوس/لمس (`نقرة`، `ماوس_س`)، تصادم (`تصادم`، `مسافة`)، إيموجي (`رمز`)، `خلفية`، وشخصيات بكسل (`بكسلات`) من محرر 🎨 مدمج
- **موسيقى**: `لحن("دو ري مي+ صول:2")` وبيانو 🎹 بينزّل اللحن في الكود
- **تطبيق ومشاركة**: 📱 رابط بيفتح برنامجك لوحده، و📦 ملف HTML واحد يشتغل أوفلاين
- **تحفيز**: 🏆 إنجازات وشهادة، و⭐ تحدي يومي بسلسلة أيام، و✨ تنسيق تلقائي للكود
- **مشاركة برابط**: الكود بيتخزن في الرابط نفسه
- **وضع ليلي ونهاري**، ومتجاوب مع الموبايل

## مثال: لعبة صغيرة

```
خلي س = ٠
كرر ٢٠٠ {
  امسح_اللوحة()
  ارفع()
  اذهب(س، ٠)
  مستطيل(٤٠، ٤٠)
  املأ()
  لو مفتاح() == "يمين" { س = س + ٨ }
  لو مفتاح() == "يسار" { س = س - ٨ }
  استنى(٥٠)
}
```

## تقنيًا

HTML + CSS + JavaScript خام (vanilla)، بدون أي مكتبات أو خطوة بناء. المفسّر في `lang.js` مبني على generators عشان يدعم وضع الخطوة والتوقف المؤقت، وبيشتغل في المتصفح وفي Node (اختبارات: `node test.js`).
